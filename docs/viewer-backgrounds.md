# Viewer backgrounds

The viewer bundles three user-requested promotional map images from Valve's
official City Never Sleeps page: https://www.playdeadlock.com/cityneversleeps .
The images are Valve artwork, not Grimoire artwork or an open-source asset pack.
They are included only as backgrounds for the Deadlock preview. No reference
viewer implementation or private game/reference capture is included.

- Broadway: https://cdn.akamai.steamstatic.com/apps/deadlock/images/react/cityneversleeps/broadway_01.jpg
- Uptown: https://cdn.fastly.steamstatic.com/apps/deadlock/images/react/cityneversleeps/uptown_01.jpg
- Times Square: https://cdn.fastly.steamstatic.com/apps/deadlock/images/react/cityneversleeps/times_square_05.jpg

All three filenames were verified in the official page's rendered image list on
2026-09-30. They are bundled locally so opening a preview makes no image network
request, and image capture works offline. Copyright remains with Valve.
